## Progress on TypeScript 7 – December 2025

**ソース:** TypeScript Blog

TypeScriptチームは、次期メジャーバージョン「TypeScript 7.0」（コードネーム「Project Corsa」）の開発進捗を報告しました。このプロジェクトは、コンパイラと言語サービスをネイティブコードに移植することを主眼としており、その目的は、生のパフォーマンス、メモリ使用量の効率化、そして並列処理能力の劇的な向上を図ることです。この大規模な取り組みは今年の初めに発表され、過去数ヶ月で大きな進展が見られており、開発が順調に進んでいることを示唆しています。これにより、開発者はより高速で効率的な開発体験を享受できることが期待されます。

🔗 [記事を読む](https://devblogs.microsoft.com/typescript/progress-on-typescript-7-december-2025/)

## Vercel Agent can now install Web Analytics and Speed insights for you

**ソース:** Vercel Blog

Vercel AgentがAIを活用し、Web AnalyticsとSpeed Insightsのプロジェクトへの自動インストールに対応しました。これは、プロジェクト設定と接続されたリポジトリを分析し、関連パッケージのインストール、必要なコードの記述、そして変更内容を含むプルリクエストの作成までを自動で行う画期的な機能です。

開発者はVercelダッシュボードのAnalyticsまたはSpeed Insightsタブから機能を有効にし、「Implement」ボタンをクリックするだけで、Agentが作業を開始します。生成されたプルリクエストを確認・マージしデプロイすると、自動的にトラッキングが開始されます。この機能は現在、全チーム向けにPublic Betaとして提供されており、開発者のインサイト導入プロセスを大幅に簡素化します。

🔗 [記事を読む](https://vercel.com/changelog/vercel-agent-installation)

## Mistral Large 3 now available on Vercel AI Gateway

**ソース:** Vercel Blog

Vercel AI Gatewayで、Mistralの最新高性能モデル「Mistral Large 3」が利用可能になりました。これはMistral史上最も強力なモデルで、410億のアクティブパラメータ（合計6750億）を持つ疎なmixture-of-experts（MoE）アーキテクチャを採用しています。

開発者はAI SDKで`model`を`mistral/mistral-large-3`に設定するだけで、追加のプロバイダーアカウントなしで手軽に利用できます。AI Gatewayは、モデル呼び出しの統合APIを提供し、利用状況とコストの追跡、リトライ・フェイルオーバー・パフォーマンス最適化、組み込みの可観測性といった、高可用性と開発効率を高める機能を提供します。

🔗 [記事を読む](https://vercel.com/changelog/mistral-large-3-now-available-on-vercel-ai-gateway)

## Announcing replication support and Intelligent-Tiering for Amazon S3 Tables

**ソース:** AWS News Blog

AWSは「Amazon S3 Tables」向けに、「レプリケーションサポート」と「インテリジェントティアリング」の新機能を提供開始しました。

レプリケーションサポートにより、AWSリージョン間やアカウントをまたいだS3テーブルの複製が簡素化され、データ保護と災害復旧の強化、リージョン間でのデータ共有が容易になります。

一方、インテリジェントティアリングは、データアクセスパターンに基づいてストレージクラスを自動的に最適化することで、手動介入なしにストレージコストの自動削減を実現します。

これらの機能は、S3テーブルを利用する開発者が、データ管理の効率性を高め、運用コストを最適化するための重要なツールとなります。

🔗 [記事を読む](https://aws.amazon.com/blogs/aws/announcing-replication-support-and-intelligent-tiering-for-amazon-s3-tables/)

## Amazon S3 Storage Lens adds performance metrics, support for billions of prefixes, and export to S3 Tables

**ソース:** AWS News Blog

Amazon S3 Storage Lensが強化され、S3利用状況の可視化と最適化に役立つ3つの新機能が追加されました。

1.  **パフォーマンスメトリクス**: S3の読み書きリクエスト、レイテンシー、エラーコードなどの詳細なメトリクスが追加され、アプリケーション性能の最適化に貢献します。
2.  **数十億プレフィックスの分析**: 無制限のプレフィックス分析に対応し、ペタバイト級の大規模データセットでも詳細な利用状況を可視化します。
3.  **S3テーブルへのエクスポート**: 集計メトリクスをS3テーブル形式でエクスポートできるようになり、Amazon Athenaなどと連携した高度な分析やカスタムレポート作成が簡素化されます。

これらの機能により、開発者はS3の利用状況を深く把握し、コストとパフォーマンスの両面で効果的な最適化を促進できます。

🔗 [記事を読む](https://aws.amazon.com/blogs/aws/amazon-s3-storage-lens-adds-performance-metrics-support-for-billions-of-prefixes-and-export-to-s3-tables/)

## Build multi-step applications and AI workflows with AWS Lambda durable functions

**ソース:** AWS News Blog
