## Add cache tags from Function responses, regardless of framework

**ソース:** Vercel Blog

Vercel は、@vercel/functions の `addCacheTag` 関数により、フレームワークを問わず Function レスポンスにキャッシュタグを追加できるようになりました。これにより、タグに基づいてキャッシュを無効化できます。これは、オリジンが消失した場合に「危険な削除」も可能になりますが、レイテンシ増加やダウンタイムのリスクがあるため注意が必要です。この機能は全プラン・全フレームワークで利用可能で、ダッシュボード、CLI、Function API、REST API から管理できます。キャッシュ無効化の詳細については、Vercel のドキュメントを参照してください。

🔗 [記事を読む](https://vercel.com/changelog/add-cache-tags-from-function-responses-regardless-of-framework)

## Google de-indexed Bear Blog and I don't know why

**ソース:** Hacker News Best

GoogleがBear Blogというブログ全体をインデックスから削除した原因不明の事象について解説した記事です。

## 「1進法」は存在しない？ - 記号一つで数を数えることの誤解

この記事は、「1進法」という表現がなぜ誤解を生むのか、その技術的な背景を解説しています。一般的に「1進法」と連想される「記号を一つだけ使って数を表現する方法」は、実際には位取り記数法としての「1進法」ではなく、単なる「数え上げ」に過ぎないことを明確にしています。

2進法のように、複数の記号（0と1）と位取りの概念を用いることで、効率的に数を表現できるのに対し、記号一つだけの表現は、例えば「●」を1つ、「●●」を2つ…と、数を表すためには記号の個数を数えるしかありません。これは、情報量を表す上で非効率的であり、計算や表現の複雑さを増大させます。

開発者にとって、この区別は、コンピュータサイエンスにおける数の表現、データ構造、アルゴリズムの設計など、根幹に関わる理解です。数値を扱う上での根本的な仕組みを正しく理解し、より効率的で洗練された実装に繋げることが重要となります。

## LangChainがOpen SWEを発表、オープンソースの非同期コーディングエージェント

**ソース:** InfoQ Japan

LangChainが、クラウド上で動作する完全オープンソースの非同期コーディングエージェント「Open SWE」を発表しました。これは、リアルタイムのコーディング支援に留まらず、開発者の既存ワークフローに統合され、より自律的かつ長期間稼働するエージェントへの進化を象徴するものです。Open SWEは、複雑なソフトウェア開発タスクを処理できる能力を持ち、開発効率の向上に貢献することが期待されます。
