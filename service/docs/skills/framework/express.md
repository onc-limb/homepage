## 経験

### 業務

- 画像・Web 記事の入稿システム（社内業務システム）の API サーバー構築
- middleware による画像バリデーションや CORS などのセキュリティ対策の実装
- Fastify とのパス一致判定アルゴリズムの違いを調査し、社内勉強会で発表

## 知識

- middleware による拡張モデル
- ルーターが登録順の線形探索でパスを照合する内部動作
- 軽量フレームワークゆえにライブラリ選定が重要という設計観（拡張子ベース判定のバリデーションライブラリの問題を特定・解決した経験から）
