## 経験

- 業務
  - 自動テスト設定
    - PR作成、ブランチマージをトリガーにした自動テスト
    - cronによる定期実行テスト
  - AWS環境への自動デプロイ設定
    - ECRへのコンテナイメージプッシュ
    - ECSへのデプロイ実行
  - GHCRを利用したDockerイメージキャッシュによるビルド高速化
  - Actionsファイルによる処理の共通化
  - Matrix記法による可読性の高いworkflowファイルの作成
  - Free Diskアクションを利用したリソース活用
- 個人
  - cronスケジュール実行によるRSS更新情報取得

## 知識

- actionsファイルでの共通化
- matrix記法での繰り返し処理
- runnerの種類(hosted runner, self host runner, larger runner)
- secrets管理
- 料金体系
