## 経験

### 業務

- Next.js 15 アプリケーションの保守（Pages Router / App Router の両構成。バックエンド担当を軸に、フロントエンド対応や Vercel の設定管理も担当）
- フルスタックアプリケーション（AWS ECS デプロイ）の運用 — SEO 対策のメタデータ設定、サイトマップの作成・運用

### 個人

- Next.js 16（App Router）+ OpenNext による Cloudflare Workers + R2 へのデプロイ構成の構築

- 大容量 WASM ライブラリ（OpenCV.js）の静的アセット同梱
- Vercel / Cloudflare などのホスティング比較選定
- 本サイト自体の構築・運用
