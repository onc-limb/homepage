# 実装計画 3: 投稿ページ（Studio）

## 概要

認証済みユーザーのみアクセスできる管理ページ `/studio` を作成する。
書籍の新規登録・編集・削除を行うUIを構築する。
計画2のAPIルートとNextAuth認証を利用する。

---

## 実装ステップ

### Step 1: Studio トップページ

**作成ファイル:** `app/studio/page.tsx`

- 認証チェック（サーバーコンポーネントで `auth()` を呼び出し、未認証ならリダイレクト）
- 管理コンテンツ一覧を表示
    - 現時点では「Books」のみ。カード形式でリンク表示
    - 将来的に他コンテンツ（例: ポートフォリオ管理など）を追加可能な構成

**UI構成:**

```
┌──────────────────────────┐
│  Studio                  │
│  コンテンツ管理           │
│                          │
│  ┌────────┐              │
│  │ 📚     │              │
│  │ Books  │              │
│  │ N冊    │              │
│  └────────┘              │
└──────────────────────────┘
```

### Step 2: 書籍管理ページ

**作成ファイル:** `app/studio/books/page.tsx`

**UI構成:**

```
┌──────────────────────────────────────┐
│  Books 管理                          │
│  [+ 新規登録ボタン]                   │
│                                      │
│  ┌──────────────────────────────────┐│
│  │ タイトル | 著者 | タグ | 操作     ││
│  │─────────────────────────────────│ │
│  │ リーダブル… | Dustin…| 設計 |✏️🗑 ││
│  │ Clean…     | Robert…| 設計 |✏️🗑 ││
│  └──────────────────────────────────┘│
└──────────────────────────────────────┘
```

- 書籍一覧をテーブル形式で表示（管理用なのでカードではなくテーブル）
- 各行に「編集」「削除」ボタン
- 「新規登録」ボタンで `/studio/books/new` へ遷移
- 新規登録・編集UIは別ページ遷移（`/studio/books/new`, `/studio/books/[id]/edit`）とする。フォーム項目が多いため別ページの方が見やすい

### Step 3: 書籍登録・編集フォーム

**フォーム項目:**

| フィールド | 入力形式            | 必須 | バリデーション  |
| ---------- | ------------------- | ---- | --------------- |
| タイトル   | テキスト入力        | 必須 | 空文字不可      |
| 著者       | テキスト入力        | 必須 | 空文字不可      |
| 出版社     | テキスト入力        | 任意 | -               |
| 出版年     | 数値入力            | 任意 | 1900〜現在年    |
| ISBN       | テキスト入力        | 任意 | -               |
| 公式URL    | URL入力             | 任意 | URL形式チェック |
| メモ       | テキストエリア      | 任意 | -               |
| タグ       | 複数選択 + 新規作成 | 任意 | -               |

**タグ入力UI:**

- 既存タグをチップ一覧で表示し、クリックで選択/解除
- テキスト入力で新規タグを追加可能（Enterで確定）
- Shadcn UIの `Combobox` をベースに複数選択+新規作成対応にカスタマイズして実装する

**フォーム状態管理:**

- zod + react-hook-form でフォーム状態管理・バリデーションを行う。型安全かつ今後のフォーム追加にも対応しやすい

**API呼び出し:**

- 新規登録: `POST /api/books`
- 更新: `PUT /api/books/[id]`
- 削除: `DELETE /api/books/[id]`（確認ダイアログ付き）

### Step 4: 削除確認

- 削除ボタン押下時に確認ダイアログを表示
- Shadcn UI の `AlertDialog` を使用
- 確認後に `DELETE /api/books/[id]` を実行

### Step 5: サインイン/サインアウトUI

**変更ファイル:** `app/studio/page.tsx` または Studio用レイアウト

- Studio ページ内にサインアウトボタンを配置
- サインインページは NextAuth デフォルトを使用（管理者専用のため素朴なUIで十分）

### Step 6: Studio用レイアウト（任意）

**作成ファイル:** `app/studio/layout.tsx`

- Studio配下の共通レイアウト
- 管理画面用の別レイアウトとする（既存サイトのHeader/Footerは非表示）
- Studio専用のシンプルなヘッダーに「Studio」タイトル・ナビゲーション・サインアウトボタンを配置

## 検証方法

- 未認証で `/studio` アクセス → サインインページへリダイレクト
- GitHubログイン後 `/studio` にアクセスできること
- 許可されていないGitHubアカウントではログイン拒否されること
- 書籍の新規登録 → 一覧に反映されること
- 書籍の編集 → 変更が保存されること
- 書籍の削除 → 確認後に削除されること
- タグの新規作成・既存タグの選択が動作すること
- `/books`（公開ページ）にも登録データが反映されること
